# ATC Radar Game

An air-traffic-control radar simulation. Vector arrivals to the runway, sequence departures, and manage waypoints to keep the skies safe.

**Live demo:** https://1326atcgame.vercel.app

## What it does

- Frame-rate-independent game loop, so the physics run the same at 30fps or 120fps
- Aircraft with 6 flight states and realistic turn and climb behavior
- Enforces real ATC separation rules, both horizontally and vertically
- Animated radar sweep rendered with Canvas gradients

## Built with

TypeScript, Canvas API, Vite
